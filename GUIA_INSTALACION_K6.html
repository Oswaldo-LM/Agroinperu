Propósito: Pruebas de Rendimiento y Carga del Capítulo III (Sección 3.x.3)

Rama Git: feature/pruebas-rendimiento-k6

1. ¿Qué es Grafana k6?

k6 es una herramienta moderna de código abierto para pruebas de carga y rendimiento de APIs y servicios web. Permite evaluar la concurrencia de usuarios simulados (VUs), tiempos de respuesta (latencia), percentiles y tasas de fallos.

2. Métodos de Instalación en Windows

Elige uno de los siguientes métodos según tu preferencia:

Opción A: Instalación con Winget (Recomendada en Windows 10/11)

Abre PowerShell o CMD y ejecuta:

winget install k6 --source winget

(Al finalizar, cierra y vuelve a abrir tu terminal para recargar el PATH).

Opción B: Instalador Oficial .MSI (Descarga Directa)

  1. Ingresa a: https://github.com/grafana/k6/releases/latest
  2. En la sección Assets, descarga el instalador: k6-vX.XX.X-amd64.msi
  3. Ejecútalo y completa el asistente de instalación.

Opción C: Uso directo con Docker (Sin instalar nada en Windows)

Si ya cuentas con Docker Desktop activo, no requieres instalar k6 en Windows. Puedes ejecutarlo mediante la imagen oficial:

docker pull grafana/k6:latest

3. Verificación de la Instalación

Para comprobar que k6 está listo en tu sistema, escribe en la terminal:

k6 version

Debe responder con la versión instalada (ej. k6 v0.5x.x (...) windows/amd64).

4. Ejecución de las Pruebas de Rendimiento en AgroIn

Asegúrate de tener levantado el backend (puerto 3000) y sitúate en la raíz del proyecto (AgroIn):

4.1. Si instalaste k6 en Windows:

# Prueba integral del sistema (15 usuarios concurrentes - Recomendada para el informe):
k6 run backend/tests/performance/full_system_load.js

# Pruebas individuales por Sprint:
k6 run backend/tests/performance/sprint1_auth_load.js
k6 run backend/tests/performance/sprint2_productos_load.js
k6 run backend/tests/performance/sprint3_pedidos_load.js

4.2. Si ejecutas k6 mediante Docker:
